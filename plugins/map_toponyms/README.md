# Historical Map Toponyms

This experimental family detects text on historical TIFF maps, prepares label
crops, recognizes Cyrillic text, and collects and georeferences place names.
It also provides Cyrillic transliteration, table matching, Visual Jev filtering,
and Label Studio import and export.

The detection and recognition nodes accept the builtin OCR service contracts.
Connect a text detector and a crop text reader to run those steps.
