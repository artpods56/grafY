# Bundled historical sample

`sample-historical-table.png` is a CC0 starter sample: an original page drawn for grafY with Pillow (Times New Roman, black rules on white), 43597 bytes. It shows a parish statistical register: a title, a census line, and ten rows of houses and population. It is not a scan of a published page.

The drawing is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). A deployment can swap this file for any public-domain archival scan. The digest below is the digest of the file in this tree.

sha256: `d9e0a68668a4c3fabf016b15ef39c8d3705d07f2641cbe1dc68628f81774ba3c`

Starter Projects and the empty-canvas sample place this file at the Workspace Library root. grafY does not create a Library folder for it. Folders belong to the people using the Workspace.
