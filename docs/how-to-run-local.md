# Run Grafy locally

1. Install the Python and web dependencies with `just install`. Start Docker
   for Keycloak. For native GIS tools, see [Run and verify a GIS raster import](how-to-run-gis.md).
2. Use `.env.example` to configure the worktree's local `.env`. Set
   `GRAFY_COMMAND_HMAC_KEY` and `GRAFY_OIDC_AUTH_WRAPPING_KEY` to separate keys
   generated by `openssl rand -base64 32`. Use the example's local OIDC issuer,
   client, origin, and SQLite settings.
3. Set `TILER_STORAGE=local`, `TILER_BUCKET=workbench-artifacts`,
   `TILER_LOCAL_ROOT` to the absolute path of the `objects` directory inside
   `GRAFY_WORKSPACE`, and `TILER_CACHE_DIR` to a writable local directory.
   Set `TILER_SIGNING_KEYS` and `GRAFY_TILER_SHARED_KEY` to the same separate
   signing key of at least 32 characters, and set
   `GRAFY_TILER_URL=http://127.0.0.1:8100`.
4. Run `just dev`. It checks for free app ports, starts Keycloak if its
   readiness check fails, and runs `just api` (including the database upgrade),
   `just tiler`, and `just web`. The supervisor prints the web, API, and tiler
   URLs after their health checks pass, at ports 3000, 8000, and 8100 by default.
   If you change `TILER_PORT`, update `GRAFY_TILER_URL` to match.
5. Open http://localhost:3000 and sign in with the imported Keycloak
   `owner` / `owner` account. The first sign-in creates its personal Workspace.

Ctrl-C or SIGTERM stops the supervised processes. Keycloak runs in a separate
Docker container. Run `just keycloak-down` when you want to stop it too.

## Mint a token for a local script

Once the owner has signed in to this database, run `just dev-pat`. It prints
one newly minted PAT for the owner's personal Workspace, with the
`view_project` scope and a one-day lifetime. For multiple capabilities, repeat
`--scope`.

```bash
just dev-pat --json --name 'Local SDK' --expires-days 2 --scope view_project --scope view_runs
```

The JSON contains `token` and `workspace_id`. The requested lifetime must fit
`GRAFY_PERSONAL_ACCESS_TOKEN_MAX_LIFETIME_SECONDS`. Use the token as a Bearer
credential on PAT-enabled API routes. Revoke it under **Personal access tokens**
in the personal Workspace's settings.

The helper requires a development configuration, a loopback HTTP web origin,
the local HTTP Keycloak `grafy` realm, and an existing plain SQLite database
file inside `GRAFY_WORKSPACE`. It looks up the imported owner's fixed OIDC
subject. Run it from the same checkout and with the same settings as the API.
