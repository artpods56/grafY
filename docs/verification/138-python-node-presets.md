[ADR 0017](../adr/0017-plugins-are-application-code-in-process.md).

and retired operator. Split text, Replace text, Join text and As Markdown have
no replacement operators or presets.

The original delivery is recorded in
[issue 138](https://github.com/artpods56/grafY/issues/138). Active removal and
GIS-first integration are tracked in
[issue 182](https://github.com/artpods56/grafY/issues/182).
